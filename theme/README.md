# ثيم المتجر

بيج + عنابي + خطوط كونتور بالخلفية.

## التركيب

1. امسح **كل** الأكواد القديمة من خانات CSS و JS بالمتجر.
2. خانة **CSS**: الصق محتوى `store.css` كامل (صورة الخطوط بآخره).
3. خانة **JS**: الصق محتوى `store.js` (سطر واحد، حوالي 2.7 كيلوبايت).

الملفات اللي تنلصق بالمتجر هي اللي بمجلد `theme/` بس. مجلد `theme/src/` فيه النسخة
المقروءة للتعديل — **لا تلصقها**، طويلة وخانة الـ JS بالمتجر تقطعها
(يطلع خطأ `Unexpected end of input`).

## وش يسوي كل ملف

**store.css**
- الخلفية: بيج مع خطوط كونتور عنابية متحركة (تنساب وتلف، CSS بس بدون JS، وتشتغل حتى لو تأثيرات الحركة مطفية بالجهاز)
  ونقشة معينات خفيفة.
- الشريط العلوي أبيض بيج.
- شريط عنوان الصفحة (breadcrumb) وأقسام `bg-light` / `bg-lighten` الرمادية تصير شفافة
  عشان الخلفية تبان (بالـ CSS، ما تحتاج JS). الكروت ما تتأثر.
- شريط الأقسام يظهر بالجوال والتابلت بس. بالكمبيوتر الأقسام موجودة أصلاً
  بالشريط العلوي، فيختفي عشان ما تتكرر.
- الفوتر كله بالنص: الشعار والوصف والتواصل بصف فوق، وعمودين الروابط (المتجر / العميل)
  تحته جنب بعض، والشريط السفلي (طرق الدفع + الحقوق) بالنص.
- توهج خفيف على الأزرار عند المرور، وستايل البنرات.

**store.js** (المصدر المقروء: `src/store.source.js`)
- شريط أقسام تحت الهيدر من روابط الأقسام الموجودة (للجوال).
- بالصفحة الرئيسية بس (`/` أو `/ar` أو `/en`)، وباقي الصفحات ما يطلع فيها بنر: البنر المتحرك تحت الهيدر، وبنر طرق الدفع فوق قسم التقييمات (يلقى عنوان القسم من نصه، مهما كان نوع العنصر).
  روابط الصور بـ `store.css` (`--st-top-img` و `--st-pay-img`)، وتقبل صورة أو GIF. الصور محفوظة بـ `img/` ومنشورة عبر jsDelivr.
- المنتج اللي لحاله بقسمه يجي بالنص (يتعرف على الكروت من زر "أضف للسلة").
- أي طبقة بيضاء كبيرة تغطي الخلفية تصير شفافة. الكروت أصغر من الحد فما تتأثر.

الكود ما ينقل ولا يحذف أي عنصر من عناصر المتجر. بس يضيف عناصره، ويغيّر لون
خلفية الطبقات البيضاء الكبيرة.

## بعد أي تعديل على الـ JS

عدّل `src/store.source.js`، وبعدها طلّع النسخة اللي تنلصق:

```
npx terser src/store.source.js -c -m --comments false -o store.js
```
