# ثيم المتجر

بيج + عنابي + خطوط كونتور بالخلفية.

## التركيب

1. امسح **كل** الأكواد القديمة من خانات CSS و JS بالمتجر.
2. خانة **CSS**: الصق محتوى `store.css` كامل (صورة الخطوط بآخره).
3. خانة **JS**: الصق محتوى `store.min.js` (سطر واحد).
   لا تلصق `store.js`، هو النسخة المقروءة للتعديل فقط. خانة الـ JS بالمتجر
   تقطع الكود الطويل، و`store.min.js` حجمه حوالي 2 كيلوبايت.

## وش يسوي كل ملف

**store.css**
- الخلفية: بيج مع خطوط كونتور عنابية متحركة (تنساب وتلف، CSS بس بدون JS، وتشتغل حتى لو تأثيرات الحركة مطفية بالجهاز)
  ونقشة معينات خفيفة.
- الشريط العلوي أبيض بيج.
- شريط الأقسام يظهر بالجوال والتابلت بس. بالكمبيوتر الأقسام موجودة أصلاً
  بالشريط العلوي، فيختفي عشان ما تتكرر.
- توهج خفيف على الأزرار عند المرور، وستايل البنرات.

**store.js**
- شريط أقسام تحت الهيدر من روابط الأقسام الموجودة (للجوال).
- بالصفحة الرئيسية (`/` أو `/ar` أو `/en`، أو أي صفحة فيها قسم التقييمات): البنر المتحرك تحت الهيدر، وبنر طرق الدفع فوق قسم التقييمات (يلقى عنوان القسم من نصه، مهما كان نوع العنصر).
  روابط الصور بأول `store.js` (`IMG` / `TOP` / `PAY`)، وتقبل صورة أو GIF أو فيديو
  mp4/webm. الصور محفوظة بـ `img/` ومنشورة عبر jsDelivr، ولو ما حمّل تنجاب من GitHub مباشرة.
- المنتج اللي لحاله بقسمه يجي بالنص (يتعرف على الكروت من زر "أضف للسلة").
- أي طبقة بيضاء كبيرة تغطي الخلفية تصير شفافة. الكروت أصغر من الحد فما تتأثر.

الكود ما ينقل ولا يحذف أي عنصر من عناصر المتجر. بس يضيف عناصره، ويغيّر لون
خلفية الطبقات البيضاء الكبيرة.

## بعد أي تعديل على store.js

```
npx terser store.js -c -m -o store.min.js
```
